# MODERN LEGAL STUDIES

当代法学系统学习平台 —— 以三部英文经典教材为纲、按学科逻辑重组的手机端法学学习网站。

**在线访问**：https://x13502239474-oss.github.io/modern-legal-studies/

## 内容底本

| 定位 | 教材 |
|---|---|
| 主线骨架 | Raymond Wacks, *Understanding Jurisprudence*, 6th ed. |
| 制度比较 | Mathias Siems, *Comparative Law*, 3rd ed. |
| 精深原典 | H. L. A. Hart, *The Concept of Law*, 3rd ed. |

## 规模

- 3 阶段 · 16 模块 · 102 个知识点，讲义合计约 34.5 万汉字，篇均 3387 字
- 每篇 11 个固定小节：核心问题、概念定义、历史背景、理论原理、核心观点、理论比较、经典争论、现实案例、案例解析、本节总结、延伸思考
- 1295 道练习（单选 / 多选 / 判断 / 填空 / 论述），配四段式详解
- 7 个真实判例研究，每个 8 要素齐全
- 500 条中英对照术语

## 功能

课程目录与阅读进度、随堂测验自动批改、错题本（重做答对自动移出）、判例研究中心（分节折叠）、术语词典、全局搜索、阶段考试、笔记与收藏、完成率统计。学习记录存浏览器本地，刷新不丢；讲义页地址带 hash，可直接分享。

## 技术说明

纯静态单页应用，无构建步骤、无后端依赖。课程数据编译为 `js/course-data.js` 随页面加载，因此直接双击本地 `index.html` 也能完整运行。页面状态用哈希表示，静态托管刷新不会 404。

## 声明

本课程为学习材料：对争议问题呈现各派论据而不给单边定论；涉及具体国家现行法时明确标注法域；历史规则不写作现行法；判例事实经核实，不虚构引文与页码。
